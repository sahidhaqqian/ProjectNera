# Official application icon

`nera-logo.png` is the official artwork supplied by Sahid Haqqi on 2026-10-13
(`Neon Space Catgirl Chibi Avatar.png`). It is retained with its original
composition and transparency. `nera.ico` contains 16, 24, 32, 48, 64, 128 and
256 pixel versions generated by `tools/make_icon.py`.

The supplied artwork is part of Project Nera's proprietary branding, separate
from third-party software and asset licenses.
